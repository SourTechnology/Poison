## Poison
Poison is a social network directory prototype. It helps users keep links to their social profiles in one place and open those services quickly.
Features

Sign-up and log-in demo screens
Personal directory of social profile links
Add and remove profiles
Search profiles by service, username, or URL
Browser-based storage for demo accounts and profiles
Responsive dark theme

# Run it

Save the site as index.html.
Open index.html in a modern web browser.
Create a demo account to enter Poison.

No build tools or dependencies are required.
# Important security note
This is a front-end prototype—not production authentication. Demo account data, including passwords, is stored in browser localStorage and is not secure. Don’t use a real password or sensitive information. A production version needs a secure authentication provider or backend.
Poison does not sign in to social platforms or collect their passwords. It stores profile links that users enter and opens those links in a new tab.
